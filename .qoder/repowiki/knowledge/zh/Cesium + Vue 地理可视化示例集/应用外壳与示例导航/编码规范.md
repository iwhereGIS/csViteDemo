- 示例组件通过 `examples.ts` 中的 `lazy()` 包装器统一以 `defineAsyncComponent` 懒加载，并共享相同的 loading/error/delay/timeout/retry 策略。
- 新增示例只需在 `examples` 数组中追加一条 `{ id, label, comp: lazy(() => import(...)) }` 记录，无需修改其他文件。
- 示例导航采用「状态 + computed」模式：`exampleId` 为 ref，`currentExample`/`currentComponent` 为 computed，模板用 `<component :is>` 动态渲染。
- 全局样式集中在 `style.css`，通过 `:root` CSS 变量定义颜色、字体、阴影等主题值，并使用 `@media (prefers-color-scheme: dark)` 覆盖暗色主题。
